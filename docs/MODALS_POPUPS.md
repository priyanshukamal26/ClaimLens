# MODALS_POPUPS.md — Modals & Overlay Components

The UI is designed to be as flat as possible, minimizing modal fatigue. However, specific interactions require overlays.

## 1. Toast Notification (`<Toast />`)
**Location**: Implemented locally within `ReviewQueue.jsx`.
**Trigger**: Clicking "Investigate" or "Dismiss" on a flagged claim.
**Behavior**: 
- Slides in from the top-right corner.
- Contains a success checkmark and action confirmation text.
- Auto-dismisses after 3000ms.
- **Styling**: Uses CSS `@keyframes slideIn`. Distinct colors based on action (`#163300` for Investigate, `#2A4D14` for Dismiss).

## 2. Review Queue Drill-Down (Inline Expansion)
**Location**: `ReviewQueue.jsx`
**Trigger**: Clicking a claim in the queue list.
**Behavior**: 
- Rather than opening a blocking modal, the UI splits into a two-pane view. The left pane shows the remaining queue, while the right pane expands to show the 3-Layer Anomaly Breakdown.
- This is an intentional UX decision to allow investigators to rapidly process claims without repeatedly opening and closing modals.

## 3. SQL Transparency View (Collapsible)
**Location**: `AskClaimLens.jsx`
**Trigger**: Expanding the "View generated SQL" section beneath an LLM response.
**Behavior**:
- Inline accordion expansion.
- Shows the raw SQL query generated by the LLM and passed by the `sqlglot` guard.
- Formatted as a monospace code block.
